# AI Code Verification Layer Example

This Python script demonstrates a simplified AI code validation layer (Vericore). It checks for syntax errors and the presence of potentially dangerous built-in functions like `eval` and `open` in AI-generated code snippets.

## Language

`python`

## How to Run

Save the code as `vericore_demo.py` and run it from your terminal using: `python3 vericore_demo.py`
